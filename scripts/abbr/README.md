# Каталог аббревиатур: как пополнять

Раздел сайта: `/abbreviations`. Данные — таблица Supabase `public.abbreviations`
(миграция `supabase/migrations/0062_abbreviations.sql`). Пока таблица не создана,
сайт показывает стартовый набор из `src/data/abbreviations.json`.

## Первый запуск (один раз)

1. Supabase → SQL Editor → вставить `supabase/migrations/0062_abbreviations.sql` → Run.
2. Там же вставить `supabase/seed/abbreviations.sql` → Run (стартовый набор).

## Добавить новые записи (без изменения кода сайта)

1. Подготовьте CSV (Excel → «Сохранить как CSV UTF-8») или JSON с колонками:

   | колонка | обязательно | значение |
   |---|---|---|
   | `lang` | да | `kk` или `ru` — язык сокращения |
   | `abbr` | да | сокращение в исходном написании |
   | `full_form` | да | полная форма на том же языке |
   | `category` | да | `emergencies`, `civil_defense`, `fire_safety`, `rescue_ops`, `industrial_safety`, `disaster_medicine`, `evacuation`, `alerting_comms`, `coordination` |
   | `source_title` | да | основной источник |
   | `source_url` | | ссылка на запись источника (https) |
   | `status` | | `confirmed` (нужен `official_url`), `base`, `needs_review` (по умолчанию) |
   | `official_title`, `official_url` | | подтверждающий официальный источник |
   | `equivalent_full` | | полная форма на другом языке — только подтверждённая |
   | `equivalent_en` | | английский эквивалент — только подтверждённый |
   | `concept` | | общий ключ понятия: одинаковый у казахской и русской записи одного понятия |
   | `explanation`, `example`, `ambiguity_note` | | пояснение, пример, примечание о многозначности |
   | `checked_at` | | дата проверки `ГГГГ-ММ-ДД` (по умолчанию — сегодня) |

2. Проверьте файл и получите SQL:

   ```
   node scripts/abbr/import.mjs новые.csv > новые.sql
   ```

   Скрипт остановится с номерами строк, если нет обязательных полей, неизвестна
   категория или статус, ссылка не https, в русской записи казахские буквы,
   статус `confirmed` без официальной ссылки. Повторы внутри файла сообщаются и
   берутся один раз.

3. Supabase → SQL Editor → вставить `новые.sql` → Run.

Повторный импорт безопасен: запись с тем же языком, сокращением и полной формой
обновляется, а не дублируется. То же сокращение с другой полной формой
сохраняется как отдельное значение.

## Правила отбора

- В каталог — только сокращения сферы гражданской защиты и МЧС; отбор по смыслу
  полной формы, а не по отдельным словам.
- Emle.kz — источник казахского написания, но не доказательство, что сокращение
  отраслевое или нормативно утверждено: такие записи — `needs_review`.
- Русские сокращения не получаются переводом казахских: у каждой записи свой
  источник.
- `confirmed` — только с официальным источником, где сокращение действительно
  употребляется (`official_url`).

## Сбор источников

`scripts/abbr/*.mjs` и workflow «Abbreviations source» собирают сырьё для отбора
(Emle.kz, статьи МЧС на gov.kz) на серверах GitHub, соблюдая robots.txt (один
запрос в секунду). Тексты «Әділет» не собираются: его API закрыт для роботов.
